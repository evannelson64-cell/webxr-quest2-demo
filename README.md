# webxr-quest2-demo

WebXR memory palace for Meta Quest 2, published via GitHub Pages.

## Features

- Four connected rooms: kitchen, fun room, cozy lounge, and gallery
- Pick up and inspect objects; they return home when released
- Trigger an object to hear its Hindi name
- Bundled Hindi MP3 clips for reliable offline playback
- High-poly glTF models in Rooms 3 and 4
- Left thumbstick locomotion and right thumbstick turning in VR

## Run locally

```sh
python3 -m http.server 8765
```

Then open `http://localhost:8765/`.
